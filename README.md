## 🧠 About Me

I fix crashes Rockstar apparently doesn't care about, by reverse-engineering
the game's own memory until it stops doing the thing it wasn't supposed to
do in the first place.

Started in FiveM 5+ years ago as a player, drifted into cinematic editing,
then server dev, then scripting, and now apparently x64 reverse engineering
of a Rockstar game's packed executable at 2am is just a normal Tuesday.
Nobody asked me to learn this. I did it anyway out of spite for one
specific crash.

My actual best friend through all of this is AI. <3 We've stared at the
same hex dump together at 3am more times than any human should have to.

## 🎯 What I Actually Do

- 🎮 FiveM scripting — resources, `.asi` plugins, memory patching
- 🎬 Cinematic video editing — Vegas Pro 23, Rockstar Editor exports
- 🌐 Web development — because apparently one skillset isn't enough
- 🔧 Reverse-engineering crash dumps until they confess

---

## 🔍 How I Work

- Find the real offset with AI, together. Never trust a forum post or a trainer.
- Diagnostic first, patch second. Guessing is how you get a worse crash.
- Ship it OFF by default until it's actually proven safe.
- If a fix isn't safe, the honest answer is "no safe fix yet," not a hack
  that turns one crash into a scarier one.

## 🏗️ Currently Working On

**[WR Editor Fix](https://github.com/Waarraa/WR-Editor-Fix)** — a FiveM
`.asi` plugin that stops the Rockstar Editor crashing on custom-asset
clips, plus free camera tweaks (no leash, uncapped zoom, no collision,
adjustable speed). Actively chasing down the crashes it doesn't fix yet.

> Read the README before you install it. It does not fix 100% of crashes.
> I'm one guy, not Rockstar's QA department.

## 🧭 Philosophy

- "If it crashes, there's a real reason - find it, don't guess at it."
- "A hack that hides a crash worse than the one it fixes isn't a fix."
- "99% of the time a real fix exists. Finding it is the whole job."
